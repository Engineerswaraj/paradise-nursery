# Paradise Nursery

Paradise Nursery is an online shopping cart application for a houseplant shop.
Visitors can browse houseplants grouped into categories, add them to a cart,
change quantities, remove items and view the total cost.

## Features
- Landing page with the company name and a **Get Started** button
- About Us section describing the company
- Product listing with 3 categories and 6 plants per category
- "Add to Cart" buttons that disable after use
- Navbar with Home, Plants and Cart links, plus a live cart item count
- Shopping cart page with quantity +/- buttons, delete button,
  per-item totals, overall total, a Checkout ("Coming Soon") button and a
  Continue Shopping button

## Built with
React, Redux Toolkit, Vite

## How to run
```
npm install
npm run dev
```
Then open the address shown in the terminal (usually http://localhost:5173).
